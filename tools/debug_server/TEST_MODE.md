# Forza测试模式使用指南

## 概述

测试模式允许在没有游戏运行的情况下，通过Web界面查看模拟的车辆数据，用于开发调试换挡算法。

## 快速开始

### 0. 配置Web界面 Token (重要!)

**使用测试模式前，必须先修改Web界面的认证Token**

#### 修改步骤

1. 打开文件: `debug_server/web_static/dashboard.js`

2. 找到第4行:
   ```javascript
   let authToken = '<your-token>';  // 生产服务器Token
   ```

3. 修改为测试模式Token:
   ```javascript
   let authToken = '<your-test-token>';  // 测试模式Token
   ```

4. 保存文件

**Token对照表**：

| 服务器类型 | Token | 用途 |
|-----------|-------|------|
| DebugServer (生产) | `<your-token>` | 连接真实游戏数据 |
| TestModeServer (测试) | `<your-test-token>` | 连接模拟测试数据 |

**注意**：完成测试后，记得将Token改回生产模式！

### 1. 启动测试服务器

```bash
cd debug_server
python test_mode_server.py
```

**输出示例**：
```
============================================================
Forza测试模式服务器
============================================================
WebSocket: 0.0.0.0:8765
认证Token: <your-test-token>
数据源: 测试模式数据源
============================================================

重要提示: 使用前请先配置Web界面Token!
详见: debug_server/TEST_MODE.md
```

### 2. 访问Web界面

在浏览器中打开：`http://localhost:8080`

**预期显示**：
- 档位：1-8档（自动变化）
- 转速：800-8000 RPM
- 速度：0-160 km/h
- 后左轮滑动：0-15%

### 3. 观察数据变化

测试模式会循环模拟驾驶场景：

**30秒循环周期**：

1. **0-15秒：加速阶段**
   - 油门逐渐加大
   - 转速上升，7000RPM自动升档
   - 速度逐渐增加

2. **15-20秒：匀速阶段**
   - 维持当前速度和档位
   - 转速相对稳定

3. **20-30秒：减速阶段**
   - 转速下降，1500RPM自动降档
   - 速度逐渐降低

然后循环重复。

## 数据字段说明

测试模式生成Web界面实际使用的字段：

| 字段 | 说明 | 范围 |
|------|------|------|
| `gear` | 当前档位 | 1-8 |
| `rpm` | 引擎转速 | 900-8000 RPM |
| `speed` | 车速 | 0-160 km/h |
| `tire_slip_RL` | 后左轮滑动比 | 0-0.15 (0-15%) |

## 高级选项

### 使用自定义端口

如果8765端口被占用，可以使用其他端口：

```bash
python test_mode_server.py --port 8766
```

然后在Web界面的连接URL中修改端口号。

### 停止服务器

按 `Ctrl+C` 停止测试服务器。

## 故障排除

### 问题1：Web界面无法连接

**可能原因**：
1. Web界面Token未修改
2. 测试服务器未启动

**解决方法**：
1. 检查`dashboard.js`第4行是否使用`<your-test-token>`
2. 检查终端中测试服务器是否正在运行
3. 查看浏览器控制台的错误信息

### 问题2：端口已被占用

**错误信息**：
```
错误: 端口 8765 已被占用，请检查:
  1. DebugServer是否正在运行
  2. 其他测试模式实例是否已启动
```

**解决方法**：
1. 停止占用端口的进程
2. 或使用其他端口：`--port 8766`

### 问题3：数据不更新

**可能原因**：Web界面JavaScript错误

**解决方法**：
1. 打开浏览器开发者工具（F12）
2. 查看Console标签页的错误信息
3. 确认WebSocket连接成功

## 与生产模式的区别

| 特性 | 测试模式 | 生产模式 |
|------|---------|----------|
| 数据来源 | 模拟生成 | 真实游戏 |
| 服务器 | TestModeServer | DebugServer |
| Token | <your-test-token> | <your-token> |
| Agent连接 | 不支持 | 支持 |
| 换挡逻辑 | 无（纯模拟） | 有（真实算法） |

## 注意事项

1. **Token切换**：切换模式时记得修改Web界面Token
2. **端口冲突**：测试服务器和生产服务器不能同时运行
3. **数据真实性**：测试数据为模拟值，不代表真实游戏物理
4. **功能限制**：测试模式不支持Agent连接和远程控制

## 最佳实践

1. **开发调试**：使用测试模式调试Web界面显示逻辑
2. **算法验证**：在测试模式下验证换挡算法的基础逻辑
3. **演示展示**：在没有游戏的情况下演示系统功能
4. **Token管理**：建议创建两个配置文件，分别用于测试和生产

# Security Policy

## Supported Versions

Currently, only the latest release on the `main` branch receives security updates. 

| Version | Supported |
|---------|-----------|
| main (latest release) | ✅ Yes |
| Older versions | ❌ No |

## Reporting a Vulnerability

**Preferred Method:** Use [GitHub Security Advisories](https://github.com/ByteLukeChan/forza_auto_gear/security/advisories) to report vulnerabilities privately.

**Alternative:** Email the project maintainer directly.

## What to Include

Please include:

- A description of the vulnerability
- Steps to reproduce the issue
- Potential impact (e.g., code execution, data exposure, denial of service)
- Any proof-of-concept code or screenshots (if applicable)

## Response Timeline

- **Initial acknowledgment:** Within 48 hours
- **Detailed assessment:** Within 7 days
- **Patch release:** As soon as feasible, based on severity

We will coordinate with you on disclosure timing and credit you for the report (unless you prefer to remain anonymous).
